# AI Policy

## Accountability

You are responsible for every line of code you submit, regardless of how it was produced. If you use AI tools, review and verify all output before committing. An agent opens a pull request or issue only at a person's request, and that person answers for it.

## AI Tool Usage

AI tools are permitted for code generation, review, and documentation.

## AI-Generated Code

AI-generated code is accepted under the standard contribution workflow.

## Disclosure

We encourage marking AI involvement in commit messages:

```text
Assisted-by: <tool name>
```

This helps the project understand tooling patterns.

## AI in CI/CD

AI tools may be used in CI/CD pipelines for code analysis and test generation.

## Training Data

This project does not opt out of AI training data collection. Standard platform terms apply.

## Licensing

AI-generated contributions must be compatible with this project's license. Confirm your AI tool's terms place no restriction on its output that conflicts with this license. Do not submit AI output that includes third-party material unless its license permits the contribution and you keep its notice and attribution. Contributors must be able to certify their submissions under the project's contribution terms.

## Policy Evolution

This policy will evolve as tooling and conventions change. Contributions to the policy itself are welcome.
